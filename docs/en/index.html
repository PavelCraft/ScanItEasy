What the app does

Combines the selected document parts, turns electronic pages into black and white, and adds visual binding elements.

The main Word file may contain any document pages. The final part — for example, a signed or certified page — is selected separately. ScanItEasy combines everything and simulates a scan of a physically bound document.

More than scan simulation

Other ScanItEasy features

Select an operation, add your files and, when necessary, configure the pages and output quality.

DOCX

Word conversion

  • DOCX → PDF;
  • DOCX → PNG;
  • DOCX → JPG.

When converting to images, every selected page is saved as a separate file.

PDF

PDF tools

  • PDF → JPG;
  • PDF → PNG;
  • combine PDFs;
  • batch compression of one or more PDFs.

You can process the entire document or only selected pages.

IMG

Image tools

  • PNG and JPG → PDF;
  • compress PNG and JPG;
  • resize while preserving proportions.

You can select several images at once.

The same rules in every mode

Select pages in any order

Every mode that provides a page-selection field follows the same rules. You can enter individual pages, forward and reverse ranges, change their order and include the same page more than once.

InputResult
1-5pages 1, 2, 3, 4, 5
5-1pages 5, 4, 3, 2, 1
7, 1-3pages 7, 1, 2, 3
3, 1-3pages 3, 1, 2, 3

Spaces are optional. Page numbering starts at 1.

Another unique functionality

Combine any number of PDFs

Add PDF files from different folders and select the required pages, ranges and sequence separately for each file. Files are placed in the resulting PDF in list order, while each file follows the general page-selection rules.
