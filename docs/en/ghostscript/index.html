How to install Ghostscript

ScanItEasy works without Ghostscript, but Ghostscript may produce a much smaller file when PDF compression is enabled.

GS

Install it only once

ScanItEasy detects Ghostscript automatically. You do not need to enter its path.

  1. 1

    Download Ghostscript

    Open the official Artifex website and download the Windows installer.

    Download Ghostscript
  2. 2

    Check your Windows system type if necessary

    If you already know your system type, skip this step.

    1. Press Win + R.
    2. Enter msinfo32, then press Enter.
    3. Find “System Type”.

    x64-based PC — download 64 bit; x86-based PC — 32 bit.

    1 / 2
  3. 3

    Install Ghostscript

    Open the downloaded EXE file and install it using the suggested settings.

    1 / 5

    After installation, restart ScanItEasy by closing and opening the application again. Restarting Windows is normally unnecessary.

Ghostscript is still not detected?

Make sure the installation completed successfully and restart ScanItEasy. If necessary, download the current installer from the official website and reinstall it.
