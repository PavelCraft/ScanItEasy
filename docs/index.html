Что делает программа

Объединяет выбранные части документа, переводит электронные страницы в чёрно-белый вид и добавляет визуальные элементы прошивки.

В основном файле Word могут находиться любые страницы документа. Последняя часть — например, подписанная или заверенная страница — загружается отдельно. ScanItEasy объединяет всё и имитирует сканирование прошитого документа.

Не только имитация сканирования

Другие возможности ScanItEasy

Выберите нужную операцию, добавьте файлы и при необходимости настройте страницы и качество результата.

DOCX

Конвертация Word

  • DOCX → PDF;
  • DOCX → PNG;
  • DOCX → JPG.

При конвертации в изображения каждая выбранная страница сохраняется отдельным файлом.

PDF

Работа с PDF

  • PDF → JPG;
  • PDF → PNG;
  • объединение PDF;
  • замена страниц содержимым PDF, DOCX, PNG или JPG;
  • пакетное сжатие одного или нескольких PDF.

Можно обрабатывать весь документ или только выбранные страницы.

IMG

Работа с изображениями

  • PNG и JPG → PDF;
  • сжатие PNG и JPG;
  • изменение размера с сохранением пропорций.

За один раз можно выбрать несколько изображений.

Единые правила во всех режимах

Выбирайте страницы в любом порядке

В каждом режиме, где доступно поле выбора страниц, используются одинаковые правила. Можно указывать отдельные страницы, прямые и обратные диапазоны, менять порядок и указывать одну и ту же страницу больше одного раза.

ВведеноРезультат
1-5страницы 1, 2, 3, 4, 5
5-1страницы 5, 4, 3, 2, 1
7, 1-3страницы 7, 1, 2, 3
3, 1-3страницы 3, 1, 2, 3

Пробелы необязательны. Нумерация страниц начинается с 1.

В режиме замены эти правила действуют для страниц заменяющего документа; в исходном PDF указывается одна страница или один непрерывный диапазон.

PDF+
Ещё одна уникальная функциональность

Объединяйте любое количество PDF

Добавляйте PDF-файлы из разных папок и для каждого файла отдельно выбирайте нужные страницы, диапазоны и их последовательность. Один PDF можно добавить несколько раз — например, поместить другой документ между его началом и окончанием. Файлы попадут в итоговый PDF в порядке списка, а внутри каждого из них действуют общие правила выбора страниц.
